# A separate factory repo drives app repos

All factory config, state, and secrets live in a factory repo that acts on app repos through GitHub App tokens, so app repos carry no factory files. Bind writes the install. The user runs it by hand, and that deploys the tick. Deleting the stack is the uninstall. Deleting the factory repo leaves the tick running (`0044-the-tick-runs-on-a-stack-the-factory-installs.md`). This rules out per-repo hooks in app repos, which is why agent behaviour is set by prompt and launch settings only.
